# 📱 MobileHub – Student Learning & Career Management Platform

## 📌 About the Project

**MobileHub** is a responsive web-based student learning and career management platform designed to help students organize their academic activities, track technical skills, plan their careers, and monitor their learning progress in one place.

The platform provides a centralized interface for managing student profiles, study schedules, skill development, career roadmaps, and achievements.

## 🎯 Objectives

- Provide a centralized platform for student academic management.
- Help students organize daily study tasks and upcoming examinations.
- Track technical skills and learning progress.
- Guide students through structured career roadmaps.
- Monitor achievements, completed courses, and projects.

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone <your-github-repository-url>
```

2. Navigate to the project directory:

```bash
cd MobileHub
```

3. Open the project in Visual Studio Code.

4. Open `index.html` in your browser or run it using the Live Server extension.

## 📱 Responsive Design

MobileHub is designed using Bootstrap 5's responsive grid system and components.

- Responsive navigation bar with a toggler.
- Fixed top navigation.
- Mobile-friendly layouts.
- Responsive cards and content sections.
- Compatible with desktop, tablet, and mobile screens.
